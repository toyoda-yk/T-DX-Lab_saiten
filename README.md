# T-DX Lab☆問題演習システム v1.25.0 SECURITY

## この版の主な変更
- 教員管理画面の権限確認を、公開JavaScript内の共通パスワードではなく学校OENアカウント＋GASで確認する方式へ変更。
- `users.json` からQR再印刷用の復号可能な暗号データを除去。公開するのは4桁番号・クラス・salt+hash等の認証情報だけ。
- QR再印刷用の平文アクセスキーはGASのScript Properties側だけに保管。一般教員はQR再印刷時に対象生徒1名分だけGASから取得。
- 生徒追加・削除・番号変更・アクセスキー発行／再発行をGAS経由で `data/users.json` へ自動反映。
- 年度更新機能を追加。生徒認証、試験・模範解答、公開分析、GAS分析データ、GAS QR保管庫をまとめて初期化。
- 年度更新時に `resetEpoch` を更新し、生徒端末に残っているT-DX Labの旧年度回答スナップショットを次回アクセス時に自動削除。
- 年度更新前に公開データのバックアップJSONを自動ダウンロード。
- GitHubトークンは引き続きGASのScript Propertiesにのみ保存し、ブラウザや公開JSONには出さない。

## GitHubへ公開されるデータ
### data/users.json
氏名・平文アクセスキー・個人回答は含みません。生徒ログイン確認に必要な4桁番号、クラス、salt+hash、QR保管有無のフラグ等のみです。

### data/exams.json
試験名、公開期間、受験対象、問題・模範解答・採点設定等です。模範解答を含むため、T-DX Labは「公開JSONを見られないこと」を不正防止の前提にはしていません。

### data/analysis.json
人数、平均点、大問別率、設問別正答率・完答率等の集計値のみです。氏名、4桁番号、個人回答、個人得点は含みません。

## GitHubへ送られないもの
- Googleフォームの生徒氏名
- 生徒ごとの元回答
- 回答Excelそのもの
- 個人別の点数
- QR再印刷用の平文アクセスキー
- GitHub Fine-grained personal access token

回答Excelは教員ブラウザ内で採点・集計し、「生徒に分析を公開」したときだけ集計済みデータをGAS経由でGitHubへ送ります。

## v1.24.x からの初回移行
1. GASの `Code.gs` をv1.25.0へ置き換え、Webアプリを新しいバージョンとして再デプロイ。
2. GitHub Pages側をv1.25.0へ更新。
3. 教員管理画面をOEN認証で開き、「システム管理者」へ進む。
4. 「旧QR暗号をGASへ移行」を1回実行するか、年間マスターCSVから移行する。
5. より安全に切り替える場合は「全員のアクセスキーを再発行」を実行し、旧QRを無効化する。

## 年度更新
年度更新はシステム管理者だけが実行できます。更新前にバックアップJSONを自動保存し、確認文字列 `RESET-YYYY` の入力を要求します。

初期化されるもの：
- 生徒認証情報
- 試験・模範解答・公開設定
- 公開済み分析
- GASに保存した分析
- GASのQR再印刷用アクセスキー
- 教員ブラウザの名簿範囲・試験下書き

自動削除されないもの：
- Googleフォーム側の回答
- 先生PCに保存したExcel/PDF
- GitHubの過去コミット履歴

GitHubの過去履歴まで物理的に消す必要がある場合は、年度更新とは別にリポジトリ履歴の再作成・履歴削除が必要です。

## GitHubトークンの年度交換
年度更新後にトークンも交換する場合は、GitHubで旧Fine-grained tokenを削除し、新しいtokenを発行してApps Scriptの `setupGitHubConnection()` を再実行してください。T-DX LabからGitHub上のtokenそのものを自動再発行・失効させることはしません。

## 重要
GASコード変更後は、Apps Scriptの「デプロイを管理」から新しいバージョンとして再デプロイしてください。既存の `/exec` URLは通常そのまま利用できます。
