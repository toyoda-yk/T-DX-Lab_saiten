# T-DX Lab☆問題演習システム v1.9

## v1.9 の主な変更
- 既に発行済みの年間アクセスキーを、後日同じQRカードとして再印刷できる「アクセスキー管理」を追加。
- 年度初めに保存した「教員保管CSV」を読み込むと、現在の users.json のハッシュと照合し、有効なキーだけ復元して再印刷できる。
- クラスで絞り込み、特定の生徒だけ選んでQRカードPDFを再印刷可能。
- 漏えい時のみ、選択した生徒だけ年間アクセスキーを個別再発行可能。
- 個別再発行は4桁番号のユーザーを追加せず、同じ生徒レコードの認証情報を置き換えるため、生徒番号は重複しない。
- 新しい users.json をGitHubに反映した時点で旧アクセスキーが無効になる。
- 教員保管CSVの書き出しは、現在画面で復元・発行できている全アクセスキーをまとめて保存する。

## 推奨運用
### 年度当初
1. STEP 0 でクラス範囲を登録
2. 年間アクセスキーを発行
3. QRカードPDFを保存して生徒へ配布
4. 教員保管CSVを安全な場所へ保存
5. users.json を書き出し、GitHub の data/users.json を置き換える

### 生徒がカードを紛失・破損した場合
1. 教員保管CSVを読み込む
2. 対象クラス・対象生徒を選択
3. 「選択した生徒のQRを再印刷」
4. 同じアクセスキーなので users.json の更新は不要

### キーが他人に見られた可能性がある場合
1. 教員保管CSVを読み込む
2. 対象生徒を選択
3. 「選択した生徒だけ再発行」
4. 新しいQRカードを配布
5. 教員保管CSVを更新保存
6. users.json を書き出してGitHubへ反映

## セキュリティ方針
- 公開用 users.json に平文の年間アクセスキーは保存しない。
- users.json には照合用 salt / hash / codeId のみ保存。
- 平文キーは教員保管CSVで教員側だけが保持する。
