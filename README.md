# T-DX Lab☆問題演習システム v1.1

## v1.1 の主な変更
- 教員管理パスワードを固定（T-DXLab9999）
- 試験専用ログインコードを全試験横断で重複防止
- 一度発行したコードの fingerprint を `issuedCodeIds` に記録
- 新規試験IDを自動生成
- 模範解答PDFの文字をブラウザ内で読み取り
- 読み取った内容から設問設定の下書きを自動生成
- 正答・配点・通常／順不同／完答・グループ・選択肢を確認画面で直接修正可能
- 合計配点チェック
- 確認後、試験を「非公開」でデータに登録し、公開管理へ渡せる

## PDF解析について
文字情報を含むPDFを対象にしたルールベース解析です。PDFのレイアウトによっては読み取れない項目があります。自動解析結果は必ず確認画面で確認・修正してから公開してください。スキャン画像のみのPDFは現段階では自動OCRしません。
