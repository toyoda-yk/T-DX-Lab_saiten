# T-DX Lab v1.26.2 登録済み試験 呼び出し・再編集 SAFE版

## 今回の変更
- 試験作成画面の先頭に「登録済み試験を呼び出す」を追加しました。
- 試験管理に残っている試験を、試験名・教科・満点・選択肢・模範解答・配点・完答/順不同・Googleフォーム連携ごと編集画面へ復元できます。
- 呼び出した試験は「登録内容を更新」で上書き保存できます。試験ID、受験対象、公開期間、公開状態は維持します。
- 「複製して新規作成」で元試験を残したまま別試験として編集できます。
- 新規登録・更新時にGitHub公開JSONへ自動保存するため、ページを閉じても「登録済み試験」から再度呼び出せます。
- Googleフォームの氏名欄は不要です。4桁番号＋解答欄だけで連携できます。

## 更新方法
SAFE版のため data/users.json・data/exams.json・data/analysis.json は含めていません。
GitHub上の既存dataフォルダはそのまま残し、本ZIPのHTML/CSS/JS等を上書きしてください。
GASは v1.4 OPERATION LOG のままで変更不要です。
