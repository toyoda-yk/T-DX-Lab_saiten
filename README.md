# T-DX Lab v1.25.8 OEN操作ログ対応 SAFE版

## 今回の更新
- OEN認証済み教員の操作を共有スプレッドシート「操作ログ」に記録
- 記録項目：日時 / OENアカウント / 権限 / 操作 / 対象 / 結果 / 詳細
- システム管理者画面から最新50件を確認可能
- ログイン、試験登録・複製、公開設定反映、回答分析、分析公開、QR再印刷、生徒管理、アクセスキー発行・再発行、完全初期化・年度更新などを記録
- GitHubトークン、年間アクセスキー、生徒氏名、個人回答・個人成績は操作ログへ記録しない

## 更新方法
1. GitHub Pages側をこのSAFE版で上書きします。dataフォルダの運用データは含まれていません。
2. Apps ScriptのCode.gsを同梱の gas/Code.gs（GAS v1.4）へ置き換えます。
3. Webアプリを「新しいバージョン」で再デプロイします。WebアプリURLは変更不要です。
4. 教員画面へOEN認証でログインすると、共有スプレッドシートに「操作ログ」シートが自動作成されます。

## 操作ログについて
- 一般教員：自分の通常操作が自動記録されます。ログを意識する必要はありません。
- システム管理者：システム管理画面の「操作ログを確認」から最新50件を確認できます。
- 全件確認：共有スプレッドシートの「操作ログ」シートを確認します。

現在運用中の data/users.json、data/exams.json、data/analysis.json は同梱していません。
