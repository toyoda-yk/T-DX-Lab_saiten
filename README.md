# T-DX Lab v1.26.7 Googleフォーム解答保存 FIX SAFE版

## 今回の修正

- v1.26.6で「回答件数は増えるが、4桁番号以外の解答欄が空になる」ケースを修正。
- Googleフォーム送信を、複数セクションで後続設問が落ちることがあった一括POST方式から、`formResponse` に `entry.*` と `pageHistory` を直接渡す方式へ変更。
- `usp=pp_url` は送信時には付けません。これは事前入力画面へ戻る原因になり得るためです。
- チェックボックス問題は同じ `entry.*` を複数回付けたまま送信します。
- 1ページフォームは `pageHistory=0`、複数ページは設定したページ数に応じて `0,1,...` を使用します。
- 先生のテスト送信は別タブで実際のGoogle側結果を確認できます。生徒の本番送信は画面を開かず裏側で同じ方式を使います。
- 氏名なし、通常フォーム/クイズ、通常数字/丸数字/全角数字、複数選択への対応は維持しています。
- 登録済み試験の呼び出し機能も維持しています。

## 更新方法

SAFE版です。既存の `data/exams.json` / `data/users.json` / `data/analysis.json` は同梱していません。GitHubへコード類を上書きしてください。

GASは既存のv1.4のままで変更不要です。更新後、トップ画面が v1.26.7 になったことを確認してください。

## 確認手順

1. 「登録済み試験を呼び出す」で対象試験を読み込みます。
2. 今回のフォームが5ページなら「Googleフォームのページ数」を5にします。セクションなしなら1です。
3. テスト送信します。
4. 別タブがGoogleフォームの送信完了画面になったことを確認します。
5. Googleフォームの回答一覧で、9999の行に4桁番号だけでなく各解答も入っていることを確認します。
6. その後、生徒画面から1件送信し、同じく解答が保存されることを確認します。
