# T-DX Lab v1.27.5 TDXDATA DETECT FIX SAFE


- `TDXDATA` の自動検出を強化しました。`TDXDATA` だけでなく、誤って `<code>TDXDATA</code>` や `&lt;code&gt;TDXDATA&lt;/code&gt;` と入力された場合も分析用データ欄として認識します。
- 分析用データ欄・4桁番号・氏名欄は、解答欄の自動割り当て候補から除外します。これにより `TDXDATA` が第1問アへ誤割り当てされる問題を防ぎます。
- ガイド内の `TDXDATA` 表記をプレーンテキストに変更し、HTMLタグを誤ってコピーしにくくしました。
- `TDXDATA` を検出した場合は「分析用データ欄を確認しました ✓」として自動利用し、先生が巨大なentry一覧から選ぶ必要はありません。

## v1.27.5 の主な変更

- Googleフォーム解析後に、T-DXがフォーム形式を自動判定します。
- 「2つ選びなさい」など**順不同で、正答値が重複しない複数選択**は、1つのチェックボックス設問にまとめても追加設定不要です。
- カ・キ・ク・ケのように**回答位置に意味がある**場合や、9・6・6・9のように**同じ値を複数回使う可能性がある**場合だけ、分析用データ欄の追加を案内します。
- 分析用データ欄が必要な場合は、Googleフォームに記述式/段落を1問追加し、事前入力時に `TDXDATA` と入れます。T-DXが自動検出するため、entry一覧から手動選択する必要はありません。
- 画面には「通常形式です。そのまま利用できます」「順不同の複数選択は追加設定不要」「分析用データ欄を追加してください」「分析用データ欄を確認しました ✓」のいずれかを表示します。


## 今回の目的
Googleフォームの作り方が先生・教材業者ごとに違っても、T-DX Labの生徒画面で採点した回答と、回答Excelを読み込んだ分析結果をできるだけ同じに保つための修正です。

特に、複数のT-DX解答欄をGoogleフォームの1つのチェックボックス質問にまとめたフォームでは、Googleフォーム側で「どの解答欄に入れたか」「同じ選択肢を何回使ったか」という情報が失われます。v1.27.5では、その場合だけ専用の記述式/段落欄へT-DXの元回答を自動保存し、分析時にその原本を優先して採点します。

## Googleフォームの対応範囲
- 1問1entryの通常フォーム：これまで通り。追加項目は不要です。
- Googleフォームのクイズ：対応。Googleフォーム側のスコアは分析には使用しません。
- 通常数字 / 丸数字 / 全角数字・英字：対応。
- セクション分割：対応。ページ数設定は従来通りです。
- 複数選択を1つのチェックボックス質問にまとめるフォーム：対応。「2つ選びなさい」など順不同・正答値重複なしなら追加設定不要です。回答位置に意味がある／同じ値を複数回使う形式だけ「T-DX分析用データ」が必要です。
- 回答によるセクション分岐：T-DX Labの試験用途では想定していません。

## T-DXが「追加設定が必要」と判定したフォームだけ行う設定
先生がフォーム形式を判断する必要はありません。事前入力URLを解析したあと、T-DXに「複数解答をまとめた設問を検出しました」と表示された場合だけ、Googleフォームに記述式または段落で次の質問を1つ追加してください。

`T-DX連携用データ（自動入力・編集不要）`

事前入力リンクを作るとき、この欄にだけ `TDXDATA` と入力します。T-DX Labが自動検出するため、entry番号を手入力する必要はありません。

生徒がT-DX Labから提出すると、この欄には `TDXRAW1|...` で始まる分析用原本が自動送信されます。これは4桁番号と各回答の並びを再採点するためのデータで、氏名は含みません。

## 分析
- T-DX分析原本がある回答は、その値を最優先して再採点します。
- 原本がない従来回答・1問1entryフォームは、これまで通りGoogleフォームの回答列から分析します。
- 共有チェックボックスなのに原本がない古い回答は、画面に「完全復元できない可能性」の警告を出します。
- `9999` のテスト回答は従来通り分析から除外します。
- 同じ4桁番号の複数回答は最新だけを採用します。

## 分析をリセット
回答分析画面に［分析をリセット］を追加しました。読み込んだExcelと現在の分析表示だけをクリアします。

削除されないもの：
- 試験登録・模範解答
- Googleフォームの回答
- すでに生徒へ公開済みの分析

## 更新方法
SAFE版です。`data/exams.json` / `data/users.json` / `data/analysis.json` は同梱していません。GitHubへコード類を上書きしてください。

GASは既存の v1.4 のままで変更不要です。

## 現在の自作フォームを確認する手順
1. まず今のまま事前入力URLをT-DXへ貼り、「連携情報を解析」。
2. 「通常形式です。そのまま利用できます」または「順不同の複数選択…追加設定不要」と出たら、そのままテスト送信へ進む。
3. 「複数解答をまとめた設問を検出しました」と出た場合だけ、Googleフォームに「T-DX分析用データ」を記述式/段落で1問追加。
4. 新しく「事前入力したリンクを取得」し、4桁番号を `9999`、全解答欄を仮入力、追加欄を `TDXDATA` にする。
5. 新しいURLを解析して「分析用データ欄を確認しました ✓」になればOK。entryを手動で選ぶ必要はない。
6. ページ数を確認してテスト送信し、9999・各回答（必要な場合は分析用データ）まで記録されたことを確認。
7. 登録内容を更新し、生徒画面から1件送信。Excel分析で生徒画面の得点と一致することを確認する。
