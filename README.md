# T-DX Lab v1.26.5 Googleフォーム実受信確認 SAFE版

## 今回の修正

- Googleフォームへの送信方式を、外部サイトからの単純POSTではなく、事前入力リンクと同じ query 形式で `formResponse` を開く方式へ変更しました。
- チェックボックスの複数回答は同じ `entry` を複数回付けて送るため、複数選択にも対応します。
- テスト送信はGoogleフォームを別タブで実際に開きます。先生が「回答を記録しました」等の完了画面を確認できるため、T-DX側だけで成功扱いにしません。
- さらにGoogleフォームの「回答」タブで4桁番号 `9999` と解答値が1件追加されたことを確認してから「受信を確認した」にチェックします。
- 未使用のGoogleフォーム項目がある場合の警告を強化しました。必須項目がT-DXの連携外にあると送信できません。
- 氏名欄は不要です。4桁番号＋解答だけのフォームで連携できます。
- 通常フォーム／クイズ、通常数字／丸数字／全角数字、複数選択、登録済み試験呼び出し機能は維持しています。

## 更新方法

SAFE版なので `data/` の運用データは含めていません。GitHub上の既存 `data/exams.json`、`data/users.json`、`data/analysis.json` は削除・上書きしないでください。

GASは既存版のままで変更不要です。更新後、トップ画面が v1.26.5 になったことを確認してください。

## 確認手順

1. 登録済み試験を呼び出します。
2. Googleフォームの事前入力URLを再解析します。
3. 「テスト送信・Google側で確認」を押します。
4. 別タブのGoogleフォームが完了画面になっていることを確認します。
5. Googleフォームの「回答」タブで `9999` が1件追加され、解答欄にも値が入っていることを確認します。
6. 「Googleフォームで受信を確認した」にチェックし、試験内容を更新保存します。

※ 別タブに入力画面やエラーが表示された場合は、GoogleフォームにT-DXから送っていない必須項目がないか、回答受付中か、ログイン必須／組織内限定になっていないかを確認してください。生徒はOEN/Google認証を使わないため、ログイン必須フォームはT-DXの送信先には使用できません。
