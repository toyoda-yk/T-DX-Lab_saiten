# T-DX Lab☆問題演習システム v1.23.5

## v1.23.5 の変更

- 年間マスターCSV移行時の結果を、操作ボタンの直下に即時表示します。
- 読込件数、移行成功数、キー不一致、名簿外を明示します。
- 0件移行の場合は users.json とCSVの組み合わせ違いを案内します。
- QR移行以外の処理は変更していません。

- 右上に現在のシステムバージョンを常時表示。
- 教員・生徒画面では `exams.json` / `users.json` の更新日時を表示。
- 「最新状態を再読込」ボタンを追加。反映待ちかどうかを確認しやすくした。
- `users.json` の書き出し時に `updatedAt` を記録するようにした。旧 `users.json` は HTTP の Last-Modified を表示し、取得できない場合は「日時情報なし」と表示。
- 読み込み順やQR・試験機能には変更を加えていない。
- 配布ZIPには運用用 `data/` を含めない。


## 今回の変更テーマ：QRカードの役割分担だけを整理

v1.23.5 を土台に、QRカード周辺だけを変更しています。試験作成、Googleフォーム連携、公開期間、自動終了、回答分析などの処理は変更していません。

### 一般教員
- 「QRカード再印刷」だけを使用します。
- クラスまたは4桁番号で生徒を探し、「QRを再印刷」を押します。
- 再印刷ではアクセスキーは変わりません。
- 年間マスターCSVや「QR再印刷用データ」の読み込みは不要です。
- アクセスキーの新規発行・再発行はできません。

### システム管理者（パスワード 9999）
- 年度名簿の登録
- 生徒の個別追加・編集・削除
- 未発行者への年間アクセスキー発行
- 個別アクセスキー再発行（漏えい等、本当にキー変更が必要な場合）
- 緊急時の全員再発行
- 年間マスターCSVのバックアップ
- users.json の書き出し

## v1.23.5以前からの移行（今回だけ必要）

既に発行済みのアクセスキーは、現在の users.json には認証用ハッシュしかありません。
一般教員がファイル読み込みなしで同じQRを再印刷できるようにするため、システム管理者が一度だけ移行します。

1. 教員画面にログイン
2. 「システム管理者」→ 9999
3. 「発行済・移行必要」が表示されたら、「年間マスターCSVを読み込んで移行」
4. これまで保存していた年間マスターCSVを選択
5. 「users.json」を書き出す
6. GitHub の `data/users.json` を新しい users.json で置き換える

以後、一般教員はCSV等を読み込まずQRを再印刷できます。

## users.json v6

- `credential`：生徒ログイン認証用の salt + hash
- `qrSecret`：QR再印刷用アクセスキーを暗号化したデータ
- `qrVault`：暗号化に必要なメタデータ
- 平文アクセスキーは users.json に保存しません。
- QR再印刷時は、教員ログイン中だけ復号してPDFを作成します。

## 年間マスターCSV

年間マスターCSVはシステム管理者のバックアップです。一般教員のQR再印刷には使用しません。

アクセスキーを再発行、生徒を追加・削除・番号変更した場合は、必要に応じて最新版の年間マスターCSVを保存し、users.json をGitHubへ反映してください。

## 更新時の重要ルール

この配布物に運用用の `data/` フォルダは入れていません。
GitHub上の次のファイルは、プログラム更新では上書きしないでください。

- `data/users.json`
- `data/exams.json`

`data-template/` は新規導入時のサンプルだけです。
