# T-DX Lab☆問題演習システム v1.23

## v1.23 の主な変更

### 教員画面を役割別に再整理
通常の先生が触る機能と、GitHub担当者が触る年度設定を分離しました。ログイン後は **「試験作成・模範解答の登録」** から始まります。

上部メニューは用途ごとに薄く色分けしています。

- **試験作成・模範解答**：正答・配点・選択肢・Googleフォーム連携
- **試験管理・公開**：受験対象・公開期間・複製・削除
- **回答分析**：Googleフォーム回答CSV / XLSXの集計
- **QRカード再印刷**：紛失・汚損時に現在のQRをそのまま再印刷
- **システム管理者**：年度名簿・年間アクセスキー・users.json

同じ説明を複数箇所に置かず、各画面の役割が分かる短い説明だけを残しています。カードの高さも必要以上にそろえず、無駄な余白が出にくいレイアウトにしています。

## システム管理者

教員共通ログインとは別に、年度設定へ入るための簡易ロックを追加しました。

- システム管理者パスワード：`9999`
- 年度名簿登録
- 未発行者への年間アクセスキー発行
- 年間マスターCSV
- QR再印刷用データ
- users.json
- 緊急時の全員再発行

通常の先生には、アクセスキーの発行・再発行操作を見せません。

## QRカード再印刷

一般の先生でも **同じアクセスキーのQRカードを再印刷** できます。

1. システム管理者が年度初めに **「QR再印刷用データ」** を書き出します。
2. 必要な先生が教員画面の「QRカード再印刷」で、そのデータを一度読み込みます。
3. 読み込んだデータはそのブラウザ内に保存されるため、通常は毎回読み込む必要はありません。
4. 4桁番号を選択して「選択した生徒を再印刷」を押します。

再印刷ではアクセスキーは変わりません。アクセスキーそのものを変更する「再発行」は、システム管理者パスワードで管理者機能を開いた場合だけ表示します。

`QR再印刷用データ.json` にはQRを再生成するためのアクセスキーが含まれます。GitHubには置かず、校内の限定された共有場所などで管理してください。

## 試験作成・模範解答

通常の先生はここから開始します。

1. 試験名・教科・満点・標準選択肢を設定
2. PDFまたはAIテキストから模範解答を登録
3. 正答・配点・採点方式・設問ごとの選択肢を確認
4. Googleフォームを連携
5. 非公開で試験データへ登録
6. 「試験管理・公開」で対象者と公開期間を設定

数字・英字・カタカナ（ア〜ト）の標準選択肢に対応し、設問ごとの個別変更もできます。

## 公開管理

日時による自動管理を継続します。

- 非公開：生徒には表示しない
- 公開予定：開始日時前
- 公開中：対象生徒に表示
- 終了（自動）：終了日時を過ぎると生徒画面から消える
- 終了（手動）：データを残したまま即時終了
- 完全削除：T-DX Labの試験データ自体を削除

試験作成時に終了日時まで余裕を持って設定すれば、終了時にGitHub担当者へ再送する必要はありません。

## 回答分析

Googleフォームの回答CSV / XLSXを読み込み、受験者数・平均点・得点分布・大問別正答率・設問別正答率を集計します。

## パスワードについて

- 教員管理画面：`T-DXLab9999`
- システム管理者：`9999`

どちらもGitHub Pages上の静的ページで使う誤操作防止用の簡易ロックです。サーバー側認証ではありません。

## アップデート時の data フォルダ

運用中の `data/users.json` と `data/exams.json` はZIPに同梱していません。GitHub上の `data/` フォルダはそのまま残し、本体ファイルだけ更新してください。ZIPには初期化用の `data-template/` のみ含まれます。
