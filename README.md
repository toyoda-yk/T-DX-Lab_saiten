# T-DX Lab☆問題演習システム v1.24.1

## v1.24.1 の主な変更

### 1. QR再印刷をCSV不要に変更
一般教員は教員管理画面へログイン後、**「QRカード再印刷」→ クラス・生徒を選択 →「選択した生徒を再印刷」**だけで、現在有効なアクセスキーと同じQRカードを再生成できます。

- QR再印刷ではアクセスキーは変わりません。
- 一般教員は年間マスターCSVを読み込む必要がありません。
- `users.json` には認証用の `credential`（salt+hash）に加え、QR再印刷用の `qrSecret` を保存します。
- `qrSecret` は教員ログインパスワードから生成した鍵で暗号化され、平文アクセスキーは `users.json` に保存しません。

> 注意：GitHub Pages上の静的システムであり、教員共通パスワードも校内運用向けの簡易認証です。高機密用途のサーバー認証を置き換えるものではありません。

### 2. v1.23以前のusers.jsonからの移行
旧 `users.json` には `qrSecret` がありません。システム管理者画面の

**「v1.23以前の年間マスターCSVから移行する」**

から、以前保存した年間マスターCSV（または旧QR再印刷用データ）を1回読み込んでください。

読み込み後、**`users.json` を書き出して GitHub の `data/users.json` を上書き**すると、以後は一般教員がCSVなしでQRを再印刷できます。

### 3. 年間マスターCSVの役割を明確化
年間マスターCSVは、今後は**システム管理者のバックアップ用**です。

v1.24.1形式の `users.json` があれば、教員ログイン後に暗号化データを復号して、**年間マスターCSVを後から何度でも再ダウンロード**できます。

年度初めの推奨運用：

1. 生徒名簿を登録
2. 未発行者に年間アクセスキーを発行
3. 年間マスターCSVをバックアップ保存
4. `users.json` を書き出す
5. GitHubの `data/users.json` を上書き

通常のQR紛失・汚損では、CSVもGitHub更新も不要です。

### 4. 生徒個別管理
システム管理者画面に**登録生徒一覧**を追加しました。

- クラス絞り込み
- 4桁番号検索
- 生徒を1名追加
- 4桁番号の個別編集
- 生徒の個別削除
- アクセス発行状態・QR再印刷可否の確認

4桁番号を変更するとQR内の番号も変わるため、変更後は新しいQRカードを再印刷してください。

生徒を追加・編集・削除した場合は、新しい `users.json` をGitHubへ反映します。個別受験対象に指定されている4桁番号を変更・削除した場合は、この画面内の試験データも更新するため、案内に従って `exams.json` も書き出してください。

### 5. アクセスキー再発行時の運用
「QR再印刷」と「アクセスキー再発行」は別操作です。

- **QR再印刷**：同じキー・同じQR。一般教員可。ファイル更新不要。
- **アクセスキー再発行**：新しいキーに変更。システム管理者のみ。古いQRは無効。

アクセスキーを再発行した場合：

1. 新しいQRカードを本人へ配布
2. `users.json` を書き出して GitHub の `data/users.json` を上書き
3. 年間マスターCSVを再ダウンロードし、バックアップを最新版へ置き換え

### 6. スマホのキャッシュ対策
- CSS / JavaScriptを `?v=1.24.1` 付きで読み込み
- `users.json` / `exams.json` は `cache: no-store` + 時刻付きURLで取得
- 教員画面・生徒画面に **v1.24.1** 表示
- **「最新版を再読込」** ボタンを追加
- トップ画面から `student.html?v=1.24.1` / `teacher.html?v=1.24.1` へ遷移

GitHub Pages自体のデプロイが完了する前は最新版になりませんが、デプロイ後のスマホ側キャッシュ残りを減らします。

## 通常教員の画面
通常は次の4つだけを使います。

- **試験作成・模範解答**：正答・配点・選択肢・Googleフォーム連携
- **試験管理・公開**：対象者・公開期間・複製・削除
- **回答分析**：Googleフォーム回答CSV / XLSXの集計
- **QRカード再印刷**：紛失・汚損時に同じQRを再印刷

## システム管理者
- システム管理者パスワード：`9999`
- 年度名簿登録
- 生徒個別編集・削除
- 年間アクセスキー新規発行・再発行
- 年間マスターCSV（バックアップ）
- `users.json` 出力
- 旧データからv1.24.1形式への移行

## 教員管理ログイン
教員管理画面の共通ログインパスワードは従来どおりです。v1.24.1では、このログイン時に入力したパスワードをメモリ内でのみ保持し、`qrSecret` の暗号化・復号に使用します。画面をロックすると保持しているパスワードは破棄します。

## アップデート時のdataフォルダ
運用中の `data/users.json` と `data/exams.json` はZIPに同梱しません。

GitHub上の `data/` フォルダは残したまま、本体ファイルだけv1.24.1へ更新してください。ZIPには初期化用の `data-template/` のみ含みます。

**既存運用でQR再印刷をCSV不要にするには、本体更新後にシステム管理者が旧年間マスターCSVを一度読み込み、v1.24.1形式の `users.json` を書き出して `data/users.json` を更新してください。**
