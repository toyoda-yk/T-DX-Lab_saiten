# T-DX Lab☆問題演習システム v1.3

## v1.3 の主な変更
- STEP 0「生徒名簿登録」を試験作成・公開とは独立
- クラスごとに「最初の4桁番号」と「最後の4桁番号」だけ入力して生徒を一括登録
- 試験公開時は登録済み名簿から、クラス全員または個別生徒を選択
- 生徒4桁番号を試験ごとに入力し直す欄を廃止
- PDF解析後の確認画面を、生徒の回答画面に近いカード＋選択肢形式へ変更
- 正答の選択肢をクリックしてその場で修正可能
- 配点・順不同・完答・グループ等は「詳細設定」に収納
- 教員ログイン成功後はログイン画面を完全に非表示にして管理ダッシュボードへ移動
- ログイン票印刷を A4縦 1枚につき2人分になるよう修正

## 教員用パスワード
`T-DXLab9999`

## 推奨運用
1. STEP 0で年度当初に生徒名簿を登録し、`users.json`を更新
2. STEP 1で模範解答PDFから試験を作成・確認
3. STEP 3で登録済み名簿から受験者を選択し、試験専用コードを生成
4. `exams.json` / `users.json` をGitHubの `data/` に反映
5. 回答後、STEP 2でCSV/XLSXを分析

## PDF解析について
文字情報を含むPDFを対象にしたルールベース解析です。PDFのレイアウトによっては読み取れない項目があります。自動解析結果は生徒画面風の確認画面で確認・修正してから公開してください。スキャン画像のみのPDFは現段階では自動OCRしません。

## v1.4 追加内容
