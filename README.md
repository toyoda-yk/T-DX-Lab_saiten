# T-DX Lab v1.26.3 Googleフォーム自作問題・複数セクション対応 SAFE版

## 今回の変更
- 自作Googleフォームで「4桁番号だけ記録され、解答欄が空欄になる」ケースを修正しました。
- Googleフォームの複数セクション送信に対応しました。従来の `pageHistory=0` 固定を廃止し、試験フォームの後続セクションも記録できるようにしています。
- 事前入力URLに `pageHistory` が含まれる場合はその値を保存し、ない場合は分岐なし試験向けの複数セクション互換値を使用します。
- テスト送信では、正答を独自変換するのではなく「事前入力URLに実際に入っていた値」を最優先でそのまま送信します。Googleフォーム側の選択肢と完全一致する値で確認できます。
- 0〜9 / ⓪〜⑨ / 全角数字、a〜f / 全角英字を送信時に吸収します。
- チェックボックスの複数選択は、同一entryへ複数値を送る仕様を維持しています。
- 氏名欄は引き続き不要です。4桁番号＋解答欄だけで連携できます。
- 既存の「登録済み試験を呼び出す」機能もそのまま利用できます。

## 更新方法
SAFE版のため data/users.json・data/exams.json・data/analysis.json は含めていません。
GitHub上の既存dataフォルダはそのまま残し、本ZIPのHTML/CSS/JS等を上書きしてください。
GASは v1.4 OPERATION LOG のままで変更不要です。

## 既存試験について
- v1.26.2以前に登録済みの試験もそのまま残ります。
- 複数セクション送信の修正は、新しい画面コードだけでも有効になります。
- 自作フォームの選択肢表記をより確実に合わせるため、該当試験だけ「登録済み試験を呼び出す」→事前入力URLを再解析→登録内容を更新、を1回行うことを推奨します。

## 確認
トップ画面が v1.26.3 になったことを確認してください。
テスト送信後はGoogleフォームの回答で、4桁番号「9999」だけでなく各解答欄にも値が入っていることを確認してください。
