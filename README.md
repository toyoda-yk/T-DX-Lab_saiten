# T-DX Lab☆問題演習システム v1.22

## v1.22 の主な変更

### 教員画面のUIを整理
- 同じ内容を繰り返していた説明・注意書きをまとめ、必要な情報だけを近くに配置しました。
- 余白が大きく残らないよう、カードの高さを無理に揃えず、設定済み情報はコンパクトに表示します。
- 教員画面の横幅を活用し、試験選択・現在の公開状態・操作ボタンを1か所に集約しました。
- AIテキストから模範解答を解析した場合は、空のPDFプレビュー欄を非表示にして読み取り結果を横幅いっぱいに表示します。
- Googleフォーム連携は「事前入力 → 解析 → テスト送信 → 受信確認」の4段階に整理し、詳細説明は必要なときだけ開く形にしました。

### 試験の複製
- 公開・運用画面に **「複製」** を追加しました。
- 正答・配点・採点方式・設問ごとの選択肢・Googleフォーム連携を引き継ぎます。
- 複製後は必ず **非公開・受験対象未設定** になります。
- 同じ構成の試験や動作確認用試験を、毎回ゼロから作り直す必要がありません。

### 動作確認モード
- 公開・運用画面に **「動作確認」** を追加しました。
- 「開始前」「公開中」「終了後」を切り替えて、生徒側でどう見えるかをその場で確認できます。
- プレビューだけなので、実際の公開日時・受験対象・試験データは変更しません。

### 公開管理
- v1.21の日時による自動公開・自動終了を継続します。
  - 非公開：準備中。生徒には表示しない。
  - 公開予定：開始日時前。生徒には表示しない。
  - 公開中：対象生徒に表示する。
  - 終了（自動）：終了日時を過ぎると自動で非表示。
  - 終了（手動）：先生が即時終了。データは保持。
  - 完全削除：T-DX Labの試験データ自体を削除。
- 試験ごとに「採点設定」「Googleフォーム」「受験対象」「公開期間」の準備状況をコンパクトなステータスで確認できます。
- `exams.json` の書き出し対象一覧は折りたたみ式にして、通常時の縦スクロールを減らしました。

### 選択肢
- 数字・英字に加えて **カタカナ（ア〜ト）** の標準選択肢を設定できます。
- 試験全体の標準選択肢を設定後、必要な設問だけ「この設問の選択肢を変更」で個別設定できます。

### データ互換性
- v1.21までの `published: true/false`、`status: published/unpublished/ended` と互換性があります。
- `exams.json` のデータバージョンを **9** に更新しました。
- キャッシュ対策の読込番号を `v1.22` に更新しました。

## 推奨する公開運用

1. 試験を作成し、模範解答・配点・選択肢・Googleフォーム連携を確認する。
2. 非公開で試験データへ登録する。
3. 「公開・運用」で受験対象を設定する。
4. 公開開始日時・公開終了日時を、実際の利用期間より少し余裕を持って設定する。
5. 「公開設定を反映」を押す。
6. `exams.json` を書き出してGitHub担当者へ渡す。
7. 開始時刻になると自動公開され、終了時刻を過ぎると自動で生徒画面から消える。

通常は最初の1回のGitHub反映で完了します。公開期間の変更、手動終了、完全削除を行った場合だけ、最新版の `exams.json` を再度反映してください。

## 動作確認のおすすめ

通常の表示確認は「動作確認」から行ってください。Googleフォームへの実送信まで確認したい場合は、完成済みの試験を「複製」して非公開の検証用試験として使うと、正答や設問ごとの選択肢を設定し直す必要がありません。

## Googleフォーム連携

業者作成のGoogleフォームを利用する場合は、T-DX Lab側の設問ごとの選択肢をフォーム側の選択肢に合わせて設定してください。事前入力リンクを作る際は、氏名・4桁番号・全解答欄に値を入れてからリンクを取得してください。

## 重要：アップデート時の data フォルダ

運用中の `data/users.json` と `data/exams.json` はZIPに同梱していません。GitHub上の `data/` フォルダはそのまま残し、本体ファイルだけ更新してください。ZIPには初期化用の `data-template/` のみ含まれます。
