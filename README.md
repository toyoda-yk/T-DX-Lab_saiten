# T-DX Lab☆問題演習システム v1.15

## v1.15 の主な変更

- 生徒の速報結果PDFを **A4縦1枚固定** に変更。
- PDFには「総合得点」「得点率」「大問別の得点・正答率」のみを掲載し、問題別一覧はPDFに含めない。
- 画面上の問題別結果は従来どおり確認可能。
- html2pdfによるページ分割方式をやめ、専用の速報版レイアウトを画像化してA4へ1回だけ配置する方式に変更。これにより2ページ化・途中改ページを防止。
- PDFファイル名に「速報版」を付与。
- 総合点の分母を100点固定ではなく、試験の `totalPoints` に合わせて表示。

## v1.14 の主な修正

- 生徒ログイン時に `data/users.json` と `data/exams.json` を毎回最新版で再取得するよう変更しました（`cache: no-store`＋キャッシュバスター）。
- 旧デモデータ `demo-annual-3101` を自動除外し、何もしていないのに「3101 発行済・キー未読込」が現れる問題を解消しました。本番で再発行済みの3101は除外しません。
- 試験登録完了後に「まだ生徒には公開されていません」と明示し、「受験者・公開設定へ進む」ボタンを追加しました。
- 公開管理に「書き出す試験一覧」を追加しました。`exams.json` が差分ではなく、登録済み試験をすべて含む累積ファイルであることを画面上で確認できます。
- `exams.json` のGitHub反映先を `data/exams.json` と明示し、ブラウザが `exams(1).json` 等へ改名した場合の注意を追加しました。
- v1.13 の模範解答登録レイアウト（選択肢範囲、PDFルート、AIテキストルート、リセット、配点チェック）を維持しています。

## 重要：アップデート時の data フォルダ

この v1.14 ZIP には、事故防止のため **運用中の `data/users.json` と `data/exams.json` を同梱していません**。
既存のGitHub上の `data/` フォルダはそのまま残してください。

- 生徒認証の更新時：教員画面から `users.json` を書き出し、GitHubの `data/users.json` を置き換えます。
- 試験公開の更新時：教員画面から `exams.json` を書き出し、GitHubの `data/exams.json` を置き換えます。

初回導入用の空データは `data-template/` にあります。初回のみ `data/` フォルダを作成してコピーしてください。
