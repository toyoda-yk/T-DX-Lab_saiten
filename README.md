## v1.25.2 変更点

- システム管理者画面に **「完全初期化（年度維持）」** を追加しました。
- 現在の年度は変えずに、生徒認証・試験／模範解答・公開分析・GASのQR再印刷用アクセスキー・GAS分析データを空にできます。

## GAS

同梱の `gas/Code.gs` は v1.3 SECURITY RESET です。Apps Scriptのコードを置き換えたあと、**デプロイを管理 → 編集 → 新しいバージョン → デプロイ**してください。既存のWebアプリURL、スプレッドシートID、GitHub連携設定はそのまま利用できます。

# T-DX Lab☆問題演習システム v1.24.1

## v1.24.1 変更点
- 生徒画面に **クラス分析／全体分析** を追加。設問別の正答率・完答率を、初期表示では **高い順** に並べて表示します。
- 生徒が自分で考えて振り返れるよう、AI的な「苦手」「復習すべき」の自動判定は表示せず、最高・最低・80%以上・50%未満など **データから直接読める事実だけ** を表示します。
- 同じ端末で受験した場合は自分の回答を端末内に保存し、公開分析の各設問に **○（正解）／△（一部正解）／×（不正解）** を重ねて比較できます。端末を変えた場合でもクラス・全体グラフ自体は閲覧できます。
- 教員の回答分析画面に **「生徒用 analysis.json を書き出す」** を追加。氏名・4桁番号・個人回答は含めず、全体・クラス別の集計値だけを書き出します。
- 生徒は試験の公開期間終了後でも、analysis.json が公開されていれば試験一覧から **「クラス・全体分析を見る」** を開けます。

## 生徒へ分析を公開する手順
1. 教員画面「回答分析」で試験を選び、Googleフォームからダウンロードした回答Excelを読み込む。
2. 集計内容を確認し、**「生徒用 analysis.json を書き出す」** を押す。
3. GitHub の `data/analysis.json` に上書きする。
4. 生徒がログインすると、対象試験に **「クラス・全体分析を見る」** が表示される。

### プライバシー
`analysis.json` に入るのは、クラス別／全体の人数・平均点・設問別正答率等の集計値だけです。**氏名・4桁番号・個々の回答・個人成績は書き出しません。**

## SAFE版の更新ルール
このZIPに運用中の `data/` フォルダは含めていません。GitHub更新時は、次の運用データを削除・上書きしないでください。
- `data/users.json`
- `data/exams.json`
- `data/analysis.json`（今回から追加。教員画面で書き出したときだけ手動更新）

`data-template/analysis.json` は新規導入用の空テンプレートです。

# T-DX Lab☆問題演習システム v1.23.8

## v1.23.8 の変更

今回の修正テーマは **「複製試験のGoogleフォーム確認を明確にする」** です。運用用 `data/` は含めていません。

1. **試験管理・公開に「Googleフォーム連携確認」を追加**
   - 選択中の試験が実際に使うGoogleフォームURLを表示します。
   - 「Googleフォームを開く」で送信先を直接確認できます。
   - 保存済みのentry対応数（氏名・4桁番号・解答欄）を表示します。
   - 「現在の設定でテスト送信」→ Googleフォームの「回答」で実受信確認 → チェック、の順に確認します。

2. **複製した試験はGoogleフォームを必ず「引継ぎ・未確認」に戻す**
   - 元試験のURL・entry対応は引き継ぎます。
   - 元試験の「受信確認済み」は引き継ぎません。
   - v1.23.6以前に作成済みの複製試験も、読み込み時に一度「引継ぎ・未確認」へ戻します。

3. **公開設定とGoogleフォーム確認を分離**
   - 受験対象や公開期間を設定しても、Googleフォームの確認状態は変わりません。
   - Googleフォームを使用する試験は、実受信の確認が済むまで「公開」を確定できません。

4. **複製後でもGoogleフォームを変更可能**
   - 「Googleフォームを変更・再設定する」を開き、新しい事前入力URLを貼り付けます。
   - 氏名・4桁番号・全解答欄のentry数が試験と一致した場合だけ差し替えます。
   - 差し替え後は再び「未確認」となり、テスト送信が必要です。

5. **GoogleフォームPOSTを小さく補強**
   - 教員テスト送信・生徒送信の両方に、Googleフォーム向けの追加hidden項目を付けています。
   - ブラウザからGoogleフォーム側の受理結果そのものは取得できないため、最終確認は必ずGoogleフォームの「回答」タブで行います。

6. **AI読取プロンプトの改良はv1.23.6のまま維持**
   - 問題用紙PDF＋模範解答PDFの両方をAIへ渡し、問題用紙から解答欄数・順番、模範解答から正答・配点・採点条件を照合します。

## 現在のQRカード運用

QRカードの役割分担は v1.23.3〜v1.23.5 で整理済みです。v1.23.8ではこのQR仕様は変更していません。

### 一般教員
- 「QRカード再印刷」だけを使用します。
- クラスまたは4桁番号で生徒を探し、「QRを再印刷」を押します。
- 再印刷ではアクセスキーは変わりません。
- 年間マスターCSVや「QR再印刷用データ」の読み込みは不要です。
- アクセスキーの新規発行・再発行はできません。

### システム管理者（パスワード 9999）
- 年度名簿の登録
- 生徒の個別追加・編集・削除
- 未発行者への年間アクセスキー発行
- 個別アクセスキー再発行（漏えい等、本当にキー変更が必要な場合）
- 緊急時の全員再発行
- 年間マスターCSVのバックアップ
- users.json の書き出し

## v1.23.5以前からの移行（今回だけ必要）

既に発行済みのアクセスキーは、現在の users.json には認証用ハッシュしかありません。
一般教員がファイル読み込みなしで同じQRを再印刷できるようにするため、システム管理者が一度だけ移行します。

1. 教員画面にログイン
2. 「システム管理者」→ 9999
3. 「発行済・移行必要」が表示されたら、「年間マスターCSVを読み込んで移行」
4. これまで保存していた年間マスターCSVを選択
5. 「users.json」を書き出す
6. GitHub の `data/users.json` を新しい users.json で置き換える

以後、一般教員はCSV等を読み込まずQRを再印刷できます。

## users.json v6

- `credential`：生徒ログイン認証用の salt + hash
- `qrSecret`：QR再印刷用アクセスキーを暗号化したデータ
- `qrVault`：暗号化に必要なメタデータ
- 平文アクセスキーは users.json に保存しません。
- QR再印刷時は、教員ログイン中だけ復号してPDFを作成します。

## 年間マスターCSV

年間マスターCSVはシステム管理者のバックアップです。一般教員のQR再印刷には使用しません。

アクセスキーを再発行、生徒を追加・削除・番号変更した場合は、必要に応じて最新版の年間マスターCSVを保存し、users.json をGitHubへ反映してください。

## 更新時の重要ルール

この配布物に運用用の `data/` フォルダは入れていません。
GitHub上の次のファイルは、プログラム更新では上書きしないでください。

- `data/users.json`
- `data/exams.json`

`data-template/` は新規導入時のサンプルだけです。
