# T-DX Lab v1.26.1 Googleフォーム複数選択対応 SAFE版

## 今回の更新
- OEN認証済み教員の操作を共有スプレッドシート「操作ログ」に記録
- 記録項目：日時 / OENアカウント / 権限 / 操作 / 対象 / 結果 / 詳細
- システム管理者画面から最新50件を確認可能
- ログイン、試験登録・複製、公開設定反映、回答分析、分析公開、QR再印刷、生徒管理、アクセスキー発行・再発行、完全初期化・年度更新などを記録
- GitHubトークン、年間アクセスキー、生徒氏名、個人回答・個人成績は操作ログへ記録しない

## 更新方法
1. GitHub Pages側をこのSAFE版で上書きします。dataフォルダの運用データは含まれていません。
2. GASはv1.4のままで変更不要です。
3. GitHub Pages側の反映後、トップ画面がv1.26.1になっていることを確認します。

## 操作ログについて
- 一般教員：自分の通常操作が自動記録されます。ログを意識する必要はありません。
- システム管理者：システム管理画面の「操作ログを確認」から最新50件を確認できます。
- 全件確認：共有スプレッドシートの「操作ログ」シートを確認します。

## SAFE版
現在運用中の data/users.json、data/exams.json、data/analysis.json は同梱していません。


## v1.26.1
- Googleフォームのチェックボックス設問で、同一entryを同じT-DXグループ内の複数解答欄に共有可能。
- 生徒送信・テスト送信とも同一entryへ複数値をPOST。
- Googleフォーム回答Excelの複数選択セルをT-DX解答欄へ展開して分析。
- 模範解答・採点方式の仕様は変更していません。


## v1.26.1
- Googleフォームの氏名項目を任意化。氏名欄なしのフォームでも連携可能。
- 生徒画面の氏名入力を任意化（入力した場合は速報PDFに表示）。
- 回答Excelの丸数字（⓪①②…⑨）を0〜9へ正規化してT-DX採点と一致。
- 氏名列がない回答Excelにも対応。テスト送信は4桁番号9999で除外可能。


## v1.26.1
- Googleフォームの氏名欄は不要。4桁番号＋解答だけで連携可能。
- 氏名entryは推測せず、明示的に設定された場合だけ利用。
- 通常フォーム／クイズを回答Excelの「スコア」列から自動判定し、どちらも分析可能。
- 0〜9、⓪〜⑨、全角数字を同じ値として分析。送信時は事前入力URLの形式に合わせる。
