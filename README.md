# T-DX Lab v1.26.4 Googleフォーム送信修正 SAFE版

## 今回の修正

- v1.26.3で追加した `pageHistory=0,1,2,...,20` の推測送信を撤回しました。
- Googleフォームに存在しないセクション番号を含めると、回答そのものが追加されない場合があるためです。
- 事前入力URLに `pageHistory` が含まれる場合は、その値をそのまま利用します。
- `pageHistory` が含まれない一般的なフォームでは、安全な `pageHistory=0` で送信します。
- v1.26.3で追加した、氏名なし・通常フォーム/クイズ両対応・数字/丸数字/全角数字・複数選択・登録済み試験呼び出し機能は維持しています。

## 更新方法

SAFE版なので `data/` の運用データは含めていません。GitHub上の既存 `data/exams.json`、`data/users.json`、`data/analysis.json` は削除・上書きしないでください。

更新後、トップ画面が v1.26.4 になったことを確認してください。GASは既存のものから変更不要です。

## 確認手順

既存試験を呼び出し、Googleフォーム連携を確認してからテスト送信してください。Googleフォームの「回答」件数が1件増え、4桁番号9999と解答値が記録されることを確認してから本番利用してください。
