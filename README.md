# T-DX Lab☆問題演習システム v1.5

## v1.5 の主な変更

- 生徒ログインを「試験ごとのコード」から **年度共通アクセスキー** 方式へ変更。
- STEP 0 で生徒名簿を登録後、未発行者に年間アクセスキーを一括発行。
- アクセスキーは 16文字相当のランダム英数字を 4文字区切りで生成し、公開用 `users.json` には平文を保存せず salt + hash のみを保存。
- 年間アクセスカードを **A4縦1枚につき2人分** のPDFで出力。
- アクセスカードには、`4桁番号 + 年間アクセスキー` を含むQRコードを印刷。
- 生徒ログイン画面に **QRコード読み取り** を追加。カメラが使えない場合は手入力でログイン可能。
- STEP 3 では試験ごとのログインコード発行を廃止し、登録済み生徒から「クラス全員」または「特定生徒」を選んで公開対象を設定。
- 試験公開時は最新版 `exams.json` を書き出し、システム管理者が GitHub の `data/exams.json` を置き換える運用に整理。
- 年度当初は `users.json` を一度 GitHub へ反映。以後は原則 `exams.json` の更新だけで運用。

## 推奨運用

### 年度当初（原則1回）
1. STEP 0で各クラスの「最初の4桁番号～最後の4桁番号」を登録。
2. 「未発行者にアクセスキーを発行」。
3. QRカードPDFと教員保管CSVを保存。
4. `users.json` を書き出し、GitHub の `data/users.json` を置き換える。
5. 生徒へアクセスカードを配布し、問題集等に貼付。

### 各試験
1. STEP 1で模範解答PDFまたはテキストから試験データを作成。
2. 採点設定を確認・修正して非公開で登録。
3. STEP 3で対象クラス・対象生徒を選択し、「公開設定を反映」。
4. `exams.json` を書き出してシステム管理者へ送付。
5. システム管理者が GitHub の `data/exams.json` を置き換える。

## QRログイン

QRコードの内容は次の形式です。

`TDX|3101|ABCD-EFGH-JKLM-NPQR`

生徒画面はQR読取後、4桁番号と年間アクセスキーを自動入力してログインします。
QR読取にはブラウザのカメラ権限が必要です。GitHub Pages（HTTPS）上で使用してください。
