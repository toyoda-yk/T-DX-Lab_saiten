# T-DX Lab☆問題演習システム v1.20

## v1.20 の主な変更

- 生徒の本番提出時に発生していた `form.submit is not a function` を修正しました。Googleフォーム送信は `HTMLFormElement.prototype.submit.call(...)` を使い、`submit` 名の隠し項目も作らない方式に変更しています。
- 選択肢範囲に **カタカナ（ア〜ト）** を追加しました。数字・英字・カタカナを組み合わせて使用できます。
- 各設問の **「この設問の選択肢を変更」** ボタンを目立たせ、設問ごとに `0,1,2,3` など個別設定しやすくしました。
- Googleフォームのテスト受信確認にチェックすると、次に **「試験データに登録（非公開）」へ進む** ことを画面に明示します。
- 試験公開状態を **非公開／公開中／終了** の3状態で管理できるようにしました。
  - 非公開：作成・確認中。生徒には表示しない。
  - 公開中：指定した受験対象の生徒に表示。
  - 終了：生徒の試験一覧から外すが、試験データは保持。
- 旧データの `published: true/false` は自動的に新しい公開状態へ読み替えるため、既存の `exams.json` と互換性があります。書き出し時も `published` は互換用に保持します。
- 生徒の試験一覧で **「教科」表示をより明確に** し、どの教科の試験か一目で分かるようにしました。
- 公開管理は **教科で絞り込み → 試験名を選択** のまま、試験名に「公開中／非公開／終了」を表示します。
- キャッシュ対策の読込番号を `v1.20` に更新しました。

## Googleフォーム連携の流れ

1. 模範解答・配点・選択肢を確認する。
2. Googleフォームで「フォームに事前入力する」を開き、氏名・4桁番号・全解答欄へテスト値を入れる。
3. 取得した事前入力リンクをT-DX Labへ貼り付ける。
4. 連携情報を解析し、氏名・4桁番号・解答欄の対応を確認する。
5. テスト送信を1件行う。
6. Googleフォームの「回答」タブで受信を確認する。
7. 「Googleフォームで受信を確認した」にチェックする。
8. **この内容で試験データに登録（非公開）** を押す。
9. 公開管理で教科 → 試験を選び、対象生徒と公開状態を設定する。
10. `exams.json` を書き出し、GitHub担当者へ渡す。

テスト送信で作られたダミー回答は、確認後にGoogleフォーム側で削除して構いません。

## 公開状態

- **非公開**：先生側で準備中。生徒には見えません。
- **公開中**：対象クラス／生徒の試験一覧に表示されます。
- **終了**：生徒一覧から非表示になりますが、採点設定やGoogleフォーム連携情報は `exams.json` に残ります。

## 重要：アップデート時の data フォルダ

v1.14以降と同様、運用中の `data/users.json` と `data/exams.json` はZIPに同梱していません。GitHub上の `data/` フォルダはそのまま残し、本体ファイルだけ更新してください。
