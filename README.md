# T-DX Lab☆問題演習システム v1.19

## v1.19 の主な変更

- Googleフォームのテスト送信で `form.submit is not a function` が出る不具合を修正しました。
- 模範解答確認画面の各設問に「選択肢を変更」ボタンを追加しました。押すと該当設問の選択肢入力欄を開いて編集できます。
- Googleフォームの解答欄数がT-DX Labより少ない場合、不足件数と「事前入力リンクですべての解答欄へ値を入れたか」を明示するようにしました。

### 1. Googleフォーム自動送信を実装
- 教員画面に **Googleフォーム連携設定** を追加しました。
- 推奨フォーマットは **氏名 → 4桁番号 → 解答欄** です。
- Googleフォームの「フォームに事前入力する」で全項目へテスト値を入れ、取得したリンクを貼り付けて解析します。
- 事前入力リンクから `entry.xxxxx` を抽出し、氏名・4桁番号・各解答欄との対応を作成します。
- 氏名・4桁番号は自動判定を試みます。必要な場合はプルダウンで修正できます。
- 各解答欄の対応表を確認・修正できます。
- **テスト送信（Googleフォームへ1件追加）** を実行し、Googleフォーム側で受信を確認してから登録できます。
- 公開用 `exams.json` には事前入力リンクやテスト用氏名は保存せず、送信先URLと `entry` 対応表だけを保存します。

### 2. 生徒提出時にGoogleフォームへ自動送信
- Googleフォーム連携済み試験では、試験画面に **氏名入力欄** を表示します。
- 4桁番号はログイン情報から自動取得します。
- 生徒が「提出して採点する」を押すと、**氏名・4桁番号・解答をGoogleフォームへ送信してから即時採点**します。
- Googleフォーム連携試験は、確実に回答を記録するため **全解答欄の回答後に提出**する仕様です。
- 氏名は `users.json` には保存しません。現在の受験・Googleフォーム送信・速報PDFにのみ使用します。
- 速報PDFの1ページ目・2ページ目に氏名を表示します。

### 3. 試験公開を教科で絞り込み
- 公開管理画面を **「教科を選択 → その教科の試験を選択」** の2段階に変更しました。
- 複数教科・多数の試験が登録されても、目的の試験を探しやすくなります。
- 試験名には「公開中／非公開」も表示します。

### 4. 公開用データ確認を改善
- `exams.json` 書き出し一覧に **Googleフォーム連携済み／未連携** を表示します。
- `exams.json` は従来どおり登録済み試験をすべて含む累積ファイルです。

### 5. キャッシュ対策
- `style.css` / `common.js` / `student.js` / `teacher.js` の読み込み番号を `?v=1.19` に更新しました。
- HTMLに no-cache 系メタ情報を追加しました。
- `data/users.json` / `data/exams.json` は `cache: no-store`＋キャッシュバスターで取得します。

## T-DX Lab用 Googleフォームの推奨フォーマット

1. **氏名**：短文回答・必須
2. **4桁番号**：短文回答・必須
3. **解答欄**：答案の順番どおりに配置

自動送信を安定させるため、次の設定を推奨します。

- メールアドレス収集：OFF
- ファイルアップロード：使用しない
- 回答者のGoogleログイン必須：OFF
- セクション分岐：使用しない
- 1ページ構成
- マーク問題は原則1つ選択の形式

Googleフォームをコピーした場合は `entry.xxxxx` が変わる可能性があるため、**フォームごとに1回、事前入力リンクを取得してT-DX Labで連携設定**してください。

## Googleフォーム連携の教員操作

1. 模範解答を登録・確認する。
2. Googleフォームを作成する。
3. Googleフォームの「フォームに事前入力する」を開く。
4. 氏名・4桁番号・全解答欄にテスト値を入力する。
5. 「リンクを取得」してT-DX Labへ貼り付ける。
6. 「連携情報を解析」を押す。
7. 氏名・4桁番号・解答欄の対応を確認する。
8. 「テスト送信（1件追加）」を押す。
9. Googleフォームの回答タブで受信を確認し、「受信を確認した」にチェックする。
10. 試験データを登録し、公開対象を設定する。
11. `exams.json` を書き出してGitHub担当者へ渡す。

## 重要：Googleフォーム送信について

T-DX LabはGitHub Pages上の静的Webアプリです。Googleフォームへの送信はブラウザからフォームの `formResponse` へ行います。教員側のテスト送信後は、**Googleフォームの回答タブに実際に1件追加されたことを必ず確認**してください。

## 重要：アップデート時の data フォルダ

v1.14以降のZIPには、事故防止のため **運用中の `data/users.json` と `data/exams.json` を同梱していません**。
既存のGitHub上の `data/` フォルダはそのまま残してください。

- 生徒認証の更新時：教員画面から `users.json` を書き出し、GitHubの `data/users.json` を置き換えます。
- 試験公開の更新時：教員画面から `exams.json` を書き出し、GitHubの `data/exams.json` を置き換えます。

初回導入用の空データは `data-template/` にあります。

## 速報PDF

- **1ページ目**：総合得点・得点率・大問別得点・大問別正答率・氏名・4桁番号
- **2ページ目**：各設問の○／×一覧・氏名・4桁番号
- 設問数に応じて2列／3列を自動調整します。
