# T-DX Lab v1.26.6 Googleフォーム自動POST送信 SAFE版

## 今回の修正

- 生徒の「回答を送信」で、Googleフォームの `formResponse` へブラウザ標準の **POST送信** を行う方式へ変更しました。
- 生徒画面ではGoogleフォームを開かず、非表示iframeへ自動送信します。採点はこれまでどおりT-DX Lab側で行います。
- 先生の「テスト送信」は、生徒と**同じPOST方式**で別タブへ送ります。Google側が受理すれば「回答を記録しました」等の完了画面になるため、実運用と同じ送信経路を確認できます。
- チェックボックスは同じ `entry` 名を複数回POSTするため、複数選択を維持しています。
- `fvv`、`draftResponse`、`pageHistory` もPOSTに含めます。事前入力URLに `pageHistory` がある場合は自動取得し、ない場合でも「Googleフォームのページ数」を入力すると `0,1,2...` を自動生成します。
- 氏名なし、通常フォーム／クイズ、通常数字／丸数字／全角数字、登録済み試験呼び出し機能は維持しています。

## 更新方法

SAFE版なので `data/` の運用データは含めていません。GitHub上の既存 `data/exams.json`、`data/users.json`、`data/analysis.json` は削除・上書きしないでください。

GASは既存版のままで変更不要です。更新後、トップ画面が v1.26.6 になったことを確認してください。

## 今回の確認手順

1. 「登録済み試験を呼び出す」から現在の試験を呼び出します。
2. Googleフォーム連携が残っていれば、そのまま使えます。複数ページの場合は「Googleフォームのページ数」を確認してください（今回のように画面下部が 1/5 ページなら 5）。必要に応じて事前入力URLを再解析してください。
3. 別タブがGoogleフォームの「回答を記録しました」等の完了画面になることを確認します。
4. Googleフォームの「回答」で `9999` が1件追加され、4桁番号だけでなく解答欄にも値が入っていることを確認します。
5. 「Googleフォームで受信を確認した」にチェックして更新保存します。
6. 生徒画面から1件送信し、Googleフォームに同じように回答が追加されれば本番経路まで確認完了です。

※ Googleフォームがログイン必須・組織内限定の場合、生徒はOEN/Google認証を使わないため自動送信できません。回答者がログイン不要で送信できる設定にしてください。
※ 複数セクションのフォームは `pageHistory` が重要です。事前入力URLに `pageHistory` が含まれる場合はT-DXがその値を引き継ぎます。
