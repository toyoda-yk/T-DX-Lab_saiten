# T-DX Lab☆問題演習システム v1.23.6

## v1.23.6 の変更

今回の変更は2点だけです。運用用 `data/` は含めていません。

1. **試験管理・公開からGoogleフォームをテスト送信**
   - 選択中の試験に保存されている `formSubmission` をそのまま使います。
   - 元試験・複製試験のどちらでも利用できます。
   - 「T-DXテスト」＋対象生徒の4桁番号＋各設問の正答をダミー回答として1件送ります。
   - 送信後はGoogleフォームの「回答」タブで実際の受信を確認してください。
   - テスト送信では試験データ、公開設定、`exams.json` の内容は変更しません。

2. **AI読取プロンプトを「問題用紙PDF＋模範解答PDF」方式へ変更**
   - 問題用紙から大問構成・解答記号・解答欄数・順番を確認。
   - 模範解答から正答・配点・採点条件を確認。
   - 両方を照合して、問題用紙の解答欄を省略しないよう指示します。
   - T-DX Labへ貼り付ける出力形式は従来どおりの4項目なので、パーサー仕様は変更していません。

## 更新時の注意

- このZIPには運用中の `data/users.json` と `data/exams.json` は入っていません。
- GitHub更新時は本体ファイルだけを上書きしてください。
- 右上表示と実際に読み込むJSが一致するよう、ローカルJSのバージョン指定を `v1.23.6` に揃えています。キャッシュ方式そのものは変更していません。

## 現在のQRカード運用

QRカードの役割分担は v1.23.3〜v1.23.5 で整理済みです。v1.23.6ではこのQR仕様は変更していません。

### 一般教員
- 「QRカード再印刷」だけを使用します。
- クラスまたは4桁番号で生徒を探し、「QRを再印刷」を押します。
- 再印刷ではアクセスキーは変わりません。
- 年間マスターCSVや「QR再印刷用データ」の読み込みは不要です。
- アクセスキーの新規発行・再発行はできません。

### システム管理者（パスワード 9999）
- 年度名簿の登録
- 生徒の個別追加・編集・削除
- 未発行者への年間アクセスキー発行
- 個別アクセスキー再発行（漏えい等、本当にキー変更が必要な場合）
- 緊急時の全員再発行
- 年間マスターCSVのバックアップ
- users.json の書き出し

## v1.23.5以前からの移行（今回だけ必要）

既に発行済みのアクセスキーは、現在の users.json には認証用ハッシュしかありません。
一般教員がファイル読み込みなしで同じQRを再印刷できるようにするため、システム管理者が一度だけ移行します。

1. 教員画面にログイン
2. 「システム管理者」→ 9999
3. 「発行済・移行必要」が表示されたら、「年間マスターCSVを読み込んで移行」
4. これまで保存していた年間マスターCSVを選択
5. 「users.json」を書き出す
6. GitHub の `data/users.json` を新しい users.json で置き換える

以後、一般教員はCSV等を読み込まずQRを再印刷できます。

## users.json v6

- `credential`：生徒ログイン認証用の salt + hash
- `qrSecret`：QR再印刷用アクセスキーを暗号化したデータ
- `qrVault`：暗号化に必要なメタデータ
- 平文アクセスキーは users.json に保存しません。
- QR再印刷時は、教員ログイン中だけ復号してPDFを作成します。

## 年間マスターCSV

年間マスターCSVはシステム管理者のバックアップです。一般教員のQR再印刷には使用しません。

アクセスキーを再発行、生徒を追加・削除・番号変更した場合は、必要に応じて最新版の年間マスターCSVを保存し、users.json をGitHubへ反映してください。

## 更新時の重要ルール

この配布物に運用用の `data/` フォルダは入れていません。
GitHub上の次のファイルは、プログラム更新では上書きしないでください。

- `data/users.json`
- `data/exams.json`

`data-template/` は新規導入時のサンプルだけです。
